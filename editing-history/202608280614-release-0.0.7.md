# Release 0.0.7 / 发布 0.0.7

## 中文

- 发布 C-safe blocking/buffer protocol v1 迁移后的首个 calcit-paint 版本。
- 版本依赖 Calcit 0.13.56 的 macOS 主线程 blocking FFI 修复，并包含 Linux worker-thread/Xvfb 兼容路径。

## English

- Release the first calcit-paint version migrated to C-safe blocking/buffer protocol v1.
- This version relies on Calcit 0.13.56's macOS main-thread blocking FFI fix and includes the Linux worker-thread/Xvfb compatibility path.
