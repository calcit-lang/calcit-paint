# 发布 0.0.8 / Release 0.0.8

- 发布采用 `calcit_native_ffi 0.1.0` 与 `cirru_edn 0.8` 的 calcit-paint。
- Cargo crate 与 Calcit 模块版本同步升级到 0.0.8。

- Release calcit-paint with `calcit_native_ffi 0.1.0` and `cirru_edn 0.8`.
