# Upgrade Calcit 0.13.64 / 升级 Calcit 0.13.64

## 中文

- 将 calcit-paint 的 Calcit 运行时要求从 0.13.58 升级到 0.13.64。
- CI 改用稳定的 setup-calcit@v1 tag，由 deps.cirru 决定项目版本，不再在 workflow 重复固定版本。
- 在运行 Snapshot 检查前增加 strict Caps 依赖守门。
- 使用 0.13.64 formatter 将兼容 string key Snapshot 规范化为 symbol key，并保持 typed wrapper、C-safe ABI、绘制与窗口语义不变。
- 规范化 README 的 19 个 Cirru 示例，并把文档格式与代码块检查加入 CI。

## English

- Upgrade calcit-paint's Calcit runtime requirement from 0.13.58 to 0.13.64.
- Use the stable setup-calcit@v1 tag in CI and derive the project version from deps.cirru instead of duplicating it in the workflow.
- Add strict Caps dependency validation before Snapshot checks.
- Use the 0.13.64 formatter to canonicalize compatible string-key Snapshot data as symbol keys while preserving typed wrappers, the C-safe ABI, rendering, and window semantics.
- Canonicalize all 19 README Cirru examples and enforce documentation formatting plus code-block checks in CI.
