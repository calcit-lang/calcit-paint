# Release 0.0.12 / 发布 0.0.12

## 中文

- 发布 calcit-paint 0.0.12。
- 使用 Calcit 0.13.64 与 canonical symbol-key Snapshot。
- 保持 calcit_native_ffi 0.1.2、C-safe buffer/blocking ABI v1、绘制与窗口语义不变。
- strict Caps、Calcit 质量门禁、64 项 Rust 测试、strict clippy、C export audit、offscreen PNG 与 Linux/Xvfb blocking smoke 均通过。

## English

- Release calcit-paint 0.0.12.
- Use Calcit 0.13.64 and the canonical symbol-key Snapshot.
- Preserve calcit_native_ffi 0.1.2, the C-safe buffer/blocking ABI v1, rendering, and window semantics.
- Strict Caps, Calcit quality gates, 64 Rust tests, strict clippy, C export audit, offscreen PNG, and the Linux/Xvfb blocking smoke all pass.
