# 发布 Calcit 模块 0.0.11 / Release Calcit module 0.0.11

## 中文

- 发布 Skia/winit 现代化、扩展 shape 与 `tag` 术语迁移后的 Calcit paint
  native 模块。
- 同步 `deps.cirru` 模块版本与内部 Cargo 构建元数据为 0.0.11。
- 本次发布仅创建并推送 Git tag，供 Calcit 模块依赖解析使用；不创建会触发
  crates.io workflow 的 GitHub Release，也不执行 `cargo publish`。

## English

- Release the Calcit paint native module after the Skia/winit modernization,
  shape extensions, and `tag` terminology migration.
- Keep the `deps.cirru` module version and internal Cargo build metadata aligned
  at 0.0.11.
- Publish only the Git tag used by Calcit module dependency resolution; do not
  create a GitHub Release that triggers the crates.io workflow or run
  `cargo publish`.
