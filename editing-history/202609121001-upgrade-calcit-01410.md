# Upgrade Calcit 0.14.10 / 升级 Calcit 0.14.10

## English

- Upgrade calcit-paint's declared Calcit runtime baseline from 0.13.77 to 0.14.10, keeping module version `0.2.0`, `calcit_native_ffi 0.1.2`, the buffer/blocking-callback v1 ABI, and public APIs unchanged.
- This supersedes the deferred 0.14.7 upgrade: the blocking `calcit.core/fs-path` strict warning was fixed upstream (calcit-lang/calcit#969, closed in the 0.14.9 milestone), and `calcit --check-only` now passes without `--compat-types`.
- Migrate strict method dispatch: replace `Option` receiver methods with the typed named functions `option:unwrap-or`, `option:unwrap`, and `option:some?`, as required by `E_ORIGINLESS_METHOD_DISPATCH` (the core `OptionMethods` bag is originless in strict mode).
- Migrate open scene-map assembly: `calcit-paint.ui` builders now combine `Map<Tag, Dynamic>`/`List<Dynamic>` scene data with `&merge` / `&list:concat` at the documented open scene boundary instead of the homogeneous-generic `merge` / `concat`, avoiding `E_ERASED_GENERIC_RELATION`.
- Rewrite the `build-art-scene` example and `returns-group-scene` test to validate through `validate-scene-structured` instead of `get`-ing values out of the open `Map<Tag, Dynamic>` scene, and refresh the affected `paint-event-from-ffi` tests to the named Option functions.
- Keep `calcit.cirru` canonical with zero unintended formatting churn, and keep the reviewed `config/calcit-quality.json` baseline unchanged at 11 schema-dynamic positions (no new `codeNil`, `codeDynamic`, or `unsafeCoerce` debt).

Validation with Calcit 0.14.10:

- `caps --strict --ci` with no version warning
- canonical Snapshot formatting with zero diff and `calcit ./calcit.cirru --check-only`
- `analyze quality --baseline config/calcit-quality.json` PASS and zero dynamic-method findings
- `docs format-md`/`check-md` for README and cookbook, and all eight `check-examples` targets
- `calcit test --require-match` (16 passed)
- `./scripts/check-cookbook.sh` and `./scripts/check-creative-art.sh` (deterministic hash unchanged)
- `cargo fmt --check`, 102 Rust tests, strict Clippy, release build, and the Actions provenance audit

## 中文

- 将 calcit-paint 声明的 Calcit 运行时基线从 0.13.77 升级到 0.14.10，保持模块版本 `0.2.0`、`calcit_native_ffi 0.1.2`、buffer/blocking-callback v1 ABI 与公开 API 不变。
- 本次取代此前延期的 0.14.7 升级：阻塞性的 `calcit.core/fs-path` 严格 warning 已在上游修复（calcit-lang/calcit#969，在 0.14.9 milestone 关闭），`calcit --check-only` 无需 `--compat-types` 即可通过。
- 迁移严格方法派发：按 `E_ORIGINLESS_METHOD_DISPATCH` 要求，将 `Option` 接收者方法替换为强类型命名函数 `option:unwrap-or`、`option:unwrap`、`option:some?`（严格模式下 core `OptionMethods` 属于无来源 legacy bag）。
- 迁移开放 scene-map 组装：`calcit-paint.ui` builder 在文档化的开放 scene 边界改用 `&merge` / `&list:concat` 组合 `Map<Tag, Dynamic>`/`List<Dynamic>` 数据，替代需要同质泛型的 `merge` / `concat`，避免 `E_ERASED_GENERIC_RELATION`。
- 将 `build-art-scene` 示例与 `returns-group-scene` 测试改为通过 `validate-scene-structured` 校验，而不再从开放 `Map<Tag, Dynamic>` scene 中 `get` 取值；并同步更新受影响的 `paint-event-from-ffi` 测试为命名 Option 函数。
- 保持 `calcit.cirru` canonical 且无意外 formatting churn，并维持已审阅的 `config/calcit-quality.json` 基线在 11 个 schema-dynamic 位置（未新增 `codeNil`、`codeDynamic` 或 `unsafeCoerce` 债务）。

使用 Calcit 0.14.10 验证：

- `caps --strict --ci` 且无版本 warning
- canonical Snapshot 格式化零 diff，以及 `calcit ./calcit.cirru --check-only`
- `analyze quality --baseline config/calcit-quality.json` PASS 且动态方法零命中
- README/cookbook 的 `docs format-md`/`check-md`，以及全部 8 个 `check-examples` target
- `calcit test --require-match`（16 passed）
- `./scripts/check-cookbook.sh` 与 `./scripts/check-creative-art.sh`（确定性 hash 不变）
- `cargo fmt --check`、102 个 Rust 测试、strict Clippy、release build 与 Actions 来源审计
