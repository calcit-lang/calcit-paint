# Upgrade Calcit 0.13.77 / 升级 Calcit 0.13.77

## English

- Upgrade calcit-paint's declared Calcit runtime baseline from 0.13.64 to 0.13.77.
- Keep the module version, `calcit_native_ffi 0.1.2`, buffer/blocking-callback v1 ABI, Skia/winit behavior, and public APIs unchanged.
- Validate the canonical Snapshot, static quality, documentation examples, Rust implementation, exported dylib symbols, offscreen rendering, cookbook, clipboard, and blocking canvas paths with the repository's existing gates.
- Track the cross-repository upgrade through calcit-lang/calcit#705 and umbrella calcit-lang/calcit#657.

Validation with the exact Calcit 0.13.77 source revision `5915ccf3`:

- `caps --calcit-version 0.13.77 --strict --ci`
- canonical Snapshot formatting with zero diff and `calcit ./calcit.cirru --check-only`
- static quality baseline, zero dynamic-method findings, README/cookbook format and example checks
- `cargo fmt --check`, 96 Rust tests, and strict Clippy
- release dylib build and macOS-equivalent audit of all required v1 exports with no legacy exports
- definition example, offscreen PNG, executable cookbook, and real-desktop blocking canvas smokes

The Linux-only clipboard/Xvfb smoke remains covered by the pull-request Actions workflow so local validation does not overwrite the user's clipboard.
