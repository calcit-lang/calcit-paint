# 2026-09-10 10:10 CST Release 0.1.0 / 发布 0.1.0

## 中文

- 发布 calcit-paint 0.1.0，完成面向 creative art 的可运行预览目标：确定性
  scene 构建、PNG 导出、黄金文件与可执行 demo 闭环。
- 纳入结构化 scene diagnostics 与 Agent 修复循环，使 Calcit 开发者和 Agents
  能使用稳定 path/code 定位无效 shape。
- 完成 SVG 资源的可选 research harness 与 Linux/Xvfb 证据；0.1.0 不暴露
  尚未达到产品门槛的公开 SVG API。
- 发布前收紧全部 GitHub Actions 来源：精确 release tag 保留版本语义，
  40 位 commit SHA 提供不可变 revision 证据，并有静态门禁防止回退。
- 本次作为 Calcit 模块发布：同步 `deps.cirru`、Rust FFI build metadata 与
  lockfile 中的本包版本，最终只推送 Git annotated tag `0.1.0`，不创建会触发
  crates.io 发布的 GitHub Release。
- 发布版本已通过 strict Caps、Actions 来源审计、Calcit check/quality/
  dynamic-method 门禁、文档代码静态检查、97 个 Rust tests、strict Clippy、
  release build、cookbook smoke 与确定性 creative-art PNG smoke（SHA-256
  `872cd3b581fd301e66c5bfd6cda5e3ef84f9c42c5d123616aa5670e95a77e0fd`）。

## English

- Release calcit-paint 0.1.0 with the runnable Creative Art Preview target:
  deterministic scene construction, PNG export, a golden artifact, and an
  executable demo loop.
- Include structured scene diagnostics and the Agent repair loop so Calcit
  developers and Agents can locate invalid shapes through stable paths/codes.
- Conclude the optional SVG research harness with Linux/Xvfb evidence; 0.1.0
  intentionally exposes no public SVG API that has not met the product gate.
- Harden every GitHub Actions reference before release: exact release tags retain
  version semantics, 40-character commit SHAs provide immutable revision
  evidence, and a static gate prevents regression.
- Publish this as a Calcit module: synchronize `deps.cirru`, Rust FFI build
  metadata, and the package version in the lockfile, then push only the annotated
  Git tag `0.1.0`. Do not create a GitHub Release that would trigger crates.io.
- Validate the release version with strict Caps, the Actions provenance audit,
  Calcit check/quality/dynamic-method gates, statically checked documentation,
  97 Rust tests, strict Clippy, a release build, the cookbook smoke, and the
  deterministic Creative Art PNG smoke (SHA-256
  `872cd3b581fd301e66c5bfd6cda5e3ef84f9c42c5d123616aa5670e95a77e0fd`).
