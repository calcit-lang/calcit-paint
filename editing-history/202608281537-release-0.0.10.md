# 发布 0.0.10 / Release 0.0.10

## 中文

- 发布基于 `calcit_native_ffi 0.1.2` 的 paint native 模块。
- 同步 Cargo crate 与 Calcit 模块版本为 0.0.10。
- 保持 buffer/blocking protocol v1 与 Calcit 0.13.57 最低版本，并清理正常 `LoopDestroyed` 退出事件的误报。

## English

- Release the paint native module backed by `calcit_native_ffi 0.1.2`.
- Synchronize the Cargo crate and Calcit module versions at 0.0.10.
- Preserve buffer/blocking protocol v1 and the Calcit 0.13.57 minimum while removing the misleading message for normal `LoopDestroyed` shutdown.
