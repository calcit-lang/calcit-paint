# 2026-09-12 01:38 CST Release 0.2.0 / 发布 0.2.0

## 中文

- 发布 calcit-paint 0.2.0，完成 `0.2.0 — Desktop Application UX` milestone：常用控件的透明 Calcit scene builders 与完整无障碍文本选择/替换。
- 新增 opt-in `calcit-paint.ui`：`button`、`touch-container`、`text-input-focus-area`、`icon-label` 与组合 `demo-scene`，输出仍是既有公开 scene map，并保留 action/path/data、focus 与无障碍语义显式（#87）。
- 文本输入支持严格、Unicode-safe 的 `:selection-start`/`:selection-end` 与 AccessKit `SetTextSelection`/`ReplaceSelectedText`，转换为强类型 Calcit 事件；native 层不修改应用状态，并拒绝非法 range/data/disabled/非 text-input（#82）。
- 单行 `:text` 增加按 grapheme cluster 的字体回退，修复中日韩/阿拉伯字符渲染成方框的问题，并新增可选 `:lang` BCP47 提示（#100）。
- 发布前门禁：Caps strict resolve、Calcit canonical format/check-only、`analyze quality --baseline`（11 个 schema-dynamic 位置，均为已审阅开放 scene 边界）、dynamic-method 零命中、README/cookbook `format-md`/`check-md`、`check-examples`、`calcit test --require-match`、`check-cookbook.sh`、`check-creative-art.sh`、Actions 来源审计、`cargo fmt/test/clippy` 与 release build。
- 本次作为 Calcit 模块发布：同步 `deps.cirru`、`Cargo.toml` 与 `Cargo.lock` 中的本包版本，最终只推送 annotated Git tag `0.2.0`，不创建会触发 crates.io 发布的 GitHub Release。
- Calcit 0.14.7 升级暂缓：严格模式命中上游 `calcit.core/fs-path` bug（calcit-lang/calcit#969，priority:p0，0.14.8 milestone），待修复后另开独立 PR。

## English

- Release calcit-paint 0.2.0, completing the `0.2.0 — Desktop Application UX` milestone: transparent Calcit scene builders for common controls and complete accessible text selection/replacement.
- Add the opt-in `calcit-paint.ui` namespace: `button`, `touch-container`, `text-input-focus-area`, `icon-label`, and the composed `demo-scene`, still emitting the public scene map and keeping `:action`/`:path`/`:data`, focus, and accessibility explicit (#87).
- Text inputs support strict, Unicode-safe `:selection-start`/`:selection-end` and AccessKit `SetTextSelection`/`ReplaceSelectedText`, translated into typed Calcit events; native code never changes application state and rejects invalid ranges/data, disabled, or non-text-input nodes (#82).
- Single-line `:text` gains per-grapheme-cluster font fallback, fixing CJK/Arabic tofu boxes, plus an optional `:lang` BCP47 hint (#100).
- Pre-release gates: strict Caps resolution, canonical Calcit format/check-only, `analyze quality --baseline` (11 schema-dynamic positions, all reviewed open scene boundaries), zero dynamic-method findings, README/cookbook `format-md`/`check-md`, `check-examples`, `calcit test --require-match`, `check-cookbook.sh`, `check-creative-art.sh`, the Actions provenance audit, `cargo fmt/test/clippy`, and a release build.
- Publish this as a Calcit module: synchronize the package version across `deps.cirru`, `Cargo.toml`, and `Cargo.lock`, then push only the annotated Git tag `0.2.0`. Do not create a GitHub Release that would trigger crates.io.
- The Calcit 0.14.7 upgrade remains deferred: strict mode hits an upstream `calcit.core/fs-path` bug (calcit-lang/calcit#969, priority:p0, 0.14.8 milestone), tracked for a separate PR after the fix lands.
